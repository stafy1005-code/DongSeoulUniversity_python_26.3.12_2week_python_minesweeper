# 💣 지뢰찾기 게임 (Minesweeper Game)

## 📖 프로젝트 소개

이 프로젝트는 Python과 Pygame을 활용하여 구현한 **지뢰찾기 게임**입니다.
기본적인 지뢰찾기 규칙에 더해 **폭발 애니메이션, 랭킹 시스템, UI 팝업 기능** 등을 추가하여 게임의 완성도를 높였습니다. 

---

## 🎮 주요 기능

### 🧠 게임 로직

* 첫 클릭 시 **주변 8칸 안전 보장**
* 빈 칸(0) 자동 확장 (Flood Fill)
* 주변 폭탄 개수 표시 (1~8)

### 💥 시각 효과

* 폭탄이 **한 번에 터지지 않고 퍼지는 애니메이션**
* 2단계 폭발 효과 구현

### 🖥️ UI 기능

* 도움말 팝업
* 일시정지 기능
* 게임 종료 팝업 (클리어 / 실패)

### 🏆 기록 시스템

* 이름 입력 후 기록 저장
* JSON 파일 기반 랭킹 관리
* 클리어 우선 + 시간 순 정렬

---

## ⚙️ 게임 규칙

1. 좌클릭 → 칸 열기
2. 우클릭 → 깃발 표시
3. 숫자 → 주변 폭탄 개수
4. 빈 칸 → 자동으로 주변 확장
5. 폭탄 클릭 시 게임 오버
6. 모든 안전 칸을 열면 클리어

## 🎯 주요 구현 기능

### ✔ 첫 클릭 안전 로직

첫 클릭 위치와 주변 8칸에는 폭탄이 생성되지 않도록 구현

### ✔ 자동 확장 알고리즘

빈 칸(0)을 클릭하면 주변 칸이 자동으로 열리는 재귀 구조

### ✔ 폭발 애니메이션

폭탄이 중심에서 바깥으로 퍼지는 **거리 기반 애니메이션 구현**

### ✔ 시간 측정 시스템

* 플레이 시간 측정
* 일시정지 시간 제외

### ✔ 랭킹 시스템

* JSON 파일로 기록 저장
* 클리어 우선 정렬
